# Plano de Auditoria da Infraestrutura Cloud

## GitHub

Identificar branch, commit implantado, workflows e integrações automáticas.

## Vercel

Identificar projeto, equipe, domínio, production branch, variáveis, URL do backend e último deployment.

Identificar projeto, ambientes, serviços, backend, domínios, rede privada, variáveis, bancos, healthchecks e políticas de deploy.

## Resultado esperado

Inventário real, arquitetura confirmada, recursos ausentes, variáveis necessárias e plano de criação sem duplicações.
